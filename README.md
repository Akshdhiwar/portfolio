# Akash Dhiwar — Portfolio

A single-page portfolio site built with plain HTML and CSS — no frameworks, build step, or dependencies.

## Structure

- `index.html` — page markup and styling (CSS is inlined to avoid a render-blocking request)

## Running locally

Just open `index.html` in a browser, or serve the folder with any static server, e.g.:

```
npx serve .
```
